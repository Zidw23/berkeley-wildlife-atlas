# East Bay Field Atlas

An interactive, responsive field-guide website introducing wildlife and habitats found around Berkeley and the wider East Bay.

## Features

- Responsive editorial-style landing page
- Searchable species directory
- Filters for birds, mammals, amphibians, and invertebrates
- Interactive species detail dialogs
- Habitat overview and field-observation prompt
- Links to local biodiversity and conservation resources
- No build step or package installation required

## Run locally

Open `index.html` in a browser. The page is self-contained and uses Google Fonts for typography; all layout, styling, data, and interactions are included in the HTML file.

## Publish with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the `main` branch and `/(root)` folder, then save.
4. GitHub Pages will publish the site at:

   https://zidw23.github.io/berkeley-wildlife-atlas/

## Content note

This is an introductory, curated selection, not a complete or authoritative species inventory. Range, seasonality, and conservation labels are intentionally presented as high-level educational context. Verify current information with local scientific sources before relying on the atlas for field identification or conservation decisions.

Useful starting points:
- [iNaturalist — Berkeley observations](https://www.inaturalist.org/places/berkeley-california)
- [Calflora](https://www.calflora.org/)
- [California Department of Fish and Wildlife](https://www.wildlife.ca.gov/)
